# TALON Tetris 🧩

TALON Tetris is a social, on-chain gaming experiment designed to drive the circulation of the $TALON token. 

## Concept
This isn't just a classic game of Tetris. It's a cooperative/competitive experience where $TALON holders can interact with the game mechanics by sending tokens to other members. 

By performing on-chain transactions, players can unlock power-ups (like specialized pieces or speed adjustments) in real-time, directly within the game. 

## How it works
1. **Connect:** Use your Base-compatible wallet.
2. **Play:** Enjoy a classic Tetris experience.
3. **Engage:** Want a boost? Send $TALON to another player/wallet to trigger on-chain events that power up your current game session.
4. **Circulate:** This simple loop turns the $TALON token into an active currency that fuels the game's energy.

## Tech Stack
* **Framework:** Next.js (React)
* **Blockchain Interaction:** Viem / BaseScan API
* **Deployment:** Vercel
